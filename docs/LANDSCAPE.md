# แผนผังที่พัก (Landscape) — คู่มือตั้งค่า ใช้งาน และติดตั้ง

ระบบวาดแผนผังพื้นที่ของที่พัก (บ้าน เต็นท์ VIP ลานกางเต็นท์ ต้นไม้ ทางเดิน ฯลฯ) ในหลังบ้าน แล้วแสดงในหน้าจอง
ให้ลูกค้าแตะเลือกที่พักจากแผนผังได้ ทำในเฟส L1–L5 (migration `0039_landscape.sql`, `0040_landscape_palette.sql` ประเภทชิ้น, `0041_landscape_looks.sql` แบบภาพ)

- หลังบ้าน: **ที่พัก → แผนผังที่พัก** (`/th/admin/landscape`)
- หน้าจอง: แผนผังอยู่เหนือรายการที่พัก เมื่อ Super Admin เปิดฟังก์ชันและมีแผนผังที่ตั้ง "แสดงในหน้าจอง"
- โค้ดหลัก: `src/shared/landscape-types.ts` (รูปแบบข้อมูล + ตรวจข้อมูล), `src/shared/geo.ts` (พิกัดโลก),
  `src/client/landscape/` (เรขาคณิต วาดรูป), `src/client/admin/landscape/` (ตัวแก้ไข), `src/client/booking/LandscapeMap.tsx`
  (หน้าจอง), `src/worker/services/landscape.service.ts`, `src/worker/services/satellite-tile.service.ts`

## 1. ตั้งค่าครั้งแรก

1. **Release เว็บ** — migration 0039–0041 รันอัตโนมัติตอน release (สถานะระบบตรวจตาราง `landscape_layouts`, `landscape_palette`)
2. **เปิดฟังก์ชัน** (Super Admin เท่านั้น) ทำได้ 2 ที่ ผลเหมือนกัน และบันทึก audit ทั้งคู่
   - หลังบ้านของเว็บ → ที่พัก → แผนผังที่พัก → ปุ่ม "เปิดแผนผัง"
   - Center → เว็บนั้น → การ์ด "ฟังก์ชันที่ Super Admin เปิด / ปิด"
3. **ภาพดาวเทียม (ถ้าจะใช้)** — ต้องมี Secret `MAPTILER_API_KEY` ของ Worker เว็บนั้น
   1. สมัครบัญชีที่ cloud.maptiler.com (ทำเอง) → **API keys** → คัดลอกคีย์
   2. **ไม่ต้อง**จำกัด HTTP Origin ของคีย์ — ระบบของเรา (Cloudflare) เป็นคนขอภาพ ไม่ใช่เบราว์เซอร์
   3. Cloudflare → Workers & Pages → Worker ของเว็บ → Settings → Variables and Secrets → Add → Type **Secret** →
      ชื่อ `MAPTILER_API_KEY` → วางคีย์ → Deploy (หรือ `npx wrangler secret put MAPTILER_API_KEY`)
   4. ไม่บังคับ: ตัวแปรธรรมดา `MAPTILER_TILESET` (ค่าเริ่มต้น `satellite-v2`) ถ้าตัวแก้ไขแจ้ง "ไม่พบชุดภาพ"
   5. **ห้ามวางคีย์ในแชท อีเมล ไฟล์ใน Git หรือภาพหน้าจอ**
4. **ตำแหน่งของเว็บ** (ไม่บังคับ): ตั้งค่า → เว็บไซต์ → ละติจูด / ลองจิจูด — แผนผังดาวเทียมใหม่จะเริ่มที่จุดนี้

ไม่มีคีย์ MapTiler: แผนผังแบบผืนผ้าว่างและรูปถ่ายใช้ได้ครบ ตัวเลือก "ภาพดาวเทียม" กดไม่ได้ และแผนผังดาวเทียมเดิมดูได้อย่างเดียว

## 3. ใช้งานตัวแก้ไข

**พื้นหลัง 3 แบบ** (เลือกตอนสร้าง เปลี่ยนแบบภายหลังไม่ได้ — ป้องกันชิ้นต่าง ๆ ย้ายที่โดยไม่ตั้งใจ)

| แบบ | เก็บพิกัดเป็น | ระยะจริง |
|---|---|---|
| ผืนผ้าว่าง | เมตรจากมุมซ้ายบน (กำหนดกว้าง × ยาว และเส้นตาราง) | จริงเสมอ |
| รูปถ่าย / ภาพมุมสูง | สัดส่วน 0…1 ของรูป (เปลี่ยนรูปแล้วชิ้นอยู่ที่เดิมเทียบกับรูป) | จริงเมื่อมีจุดอ้างอิงพิกัด หรือใส่ "ความกว้างจริง" — ไม่งั้นเป็นภาพประกอบ |
| ภาพดาวเทียม | ลองจิจูด / ละติจูด (ความยาวเป็นเมตร) | จริงเสมอ |

**เครื่องมือ**: เลือก/ย้าย (V) · เลื่อนมุมมอง (H หรือ Space ค้าง) · สี่เหลี่ยม (R) · วงกลม (C) · หลายเหลี่ยม (P) · เส้นทาง (L) ·
สัญลักษณ์ (S) · ล้อเมาส์ซูม · Ctrl+Z / Ctrl+Y · Ctrl+D ทำสำเนา · Ctrl+G จัดกลุ่ม · Delete ลบ · ลูกศรขยับ · Ctrl+S บันทึก

**แบบภาพ 3 มิติ (migration 0041)**: บ้าน 6 แบบ (บ้านจั่ว เรือนไทย โมเดิร์น ทรงเอ บังกะโล บ้านซุง) · เต็นท์ 6 แบบ (ระฆัง โดม ซาฟารี
ทีปี ทรงเอ บับเบิล) · ต้นไม้ 7 ชนิด (พุ่มกลม สน มะพร้าว/ปาล์ม จามจุรี ไผ่ ไม้ผล ไซเปรส) · พุ่มไม้ 3 แบบ · ดอกไม้ 5 แบบ (พุ่มดอกไม้
แปลงดอกไม้ ทิวลิป ทานตะวัน กระถาง) — เลือก "แบบ" และ "สีด่วน" ใต้แถบเครื่องมือก่อนวาด หรือเปลี่ยนภายหลังในแท็บคุณสมบัติ ·
**สีพื้น** = สีหลักของภาพ (หลังคา ผ้าเต็นท์ ใบไม้ กลีบดอก) · สีขอบของไม้ผล / มะพร้าว = สีผล · "เรียบ 2D" = แบบแบนเดิม ·
ชิ้นที่วาดก่อนมีระบบนี้ยังเป็นแบบแบนจนกว่าจะเลือกแบบให้ · หน้าจองแสดงภาพแบบเดียวกัน · ประเภทในแท็บ "ประเภท" ตั้งแบบเริ่มต้นได้

**ประเภทชิ้น (แท็บ "ประเภท", migration 0040)**: **เพิ่มประเภทใหม่** เช่น ศาลา สระว่ายน้ำ ลานจอดรถบัส — ตั้งชื่อ เลือกว่า
"เป็นชนิด" อะไร (บ้าน / เต็นท์ VIP / ลานกางเต็นท์ = ผูกกับการจองได้ อื่น ๆ = ชิ้นตกแต่ง) วาดเป็นรูปอะไร สี ความทึบ กลุ่ม ชั้น
และขนาดเริ่มต้น · **แก้ไข** ประเภทของระบบได้ทุกตัว (เว้นชื่อว่าง = ชื่อเดิม) · **ซ่อน / แสดง** ในแถบเครื่องมือ · **↑ ↓** เรียงลำดับ ·
**ลบ** ประเภทที่สร้างเอง (บอกจำนวนชิ้นที่วาดไว้ก่อนลบ) · **คืนค่าเดิม** ประเภทของระบบ · ทุกกรณี **ชิ้นที่วาดไว้แล้วไม่เปลี่ยน**
(เปลี่ยนประเภทของชิ้นได้ในแท็บคุณสมบัติ) · ใช้ร่วมกันทุกแผนผังของเว็บ · สร้างเองได้สูงสุด 60 ประเภท · มีบันทึกใน Audit logs

**ใช้บน iPad / จอสัมผัส**: ใช้ Safari บน iPad ได้ทั้งแนวตั้งและแนวนอน (รองรับ Apple Pencil) · สองนิ้วถ่างเพื่อซูม / ลากเพื่อเลื่อน ·
แตะเพื่อวางต้นไม้หรือจุด (วางตอนยกนิ้ว ถ้าเปลี่ยนเป็นสองนิ้วจะไม่วางเกิน) · วาดหลายเหลี่ยม / เส้นทางแล้วกดปุ่ม **"เสร็จ"** (มีปุ่ม
"ลบจุดล่าสุด" และ "ยกเลิก") · ติ๊ก **"เลือกหลายชิ้น"** แล้วแตะทีละชิ้นแทน Shift+คลิก · ลากบนที่ว่างเพื่อเลือกเป็นกรอบ ·
ปุ่มทำสำเนา / ลบ / จัดกลุ่ม / ย้อนกลับ อยู่ในแท็บคุณสมบัติและแถบด้านบน (ไม่ต้องใช้คีย์บอร์ด) · ปุ่มและจุดจับขนาดใหญ่ขึ้นสำหรับนิ้ว

**ผูกกับการจอง**: เลือกบ้าน / เต็นท์ VIP → แท็บคุณสมบัติ → "ผูกกับการจอง" → เลือกหลังในระบบ · ลานกางเต็นท์ผูกกับ
"ลานกางเต็นท์" (จำนวนเต็นท์ว่างตามระบบจอง) · ชิ้นที่ไม่ได้ผูก = ชิ้นตกแต่ง ลูกค้าเลือกจองไม่ได้

**บันทึก**: บันทึกอัตโนมัติ 2.5 วินาทีหลังแก้ · เก็บสำเนาในเบราว์เซอร์จนบันทึกสำเร็จ (ปิดแท็บ / เน็ตหลุด กลับมากู้คืนได้) ·
ถ้ามีผู้ดูแลอีกคนบันทึกก่อน ระบบไม่บันทึกทับ แต่ให้เลือก "โหลดฉบับล่าสุด" หรือ "บันทึกทับด้วยงานของฉัน"

**เผยแพร่**: ร่างไม่ปรากฏต่อลูกค้า · "เผยแพร่ร่างนี้" ตรวจว่าบ้าน / เต็นท์ที่ผูกมีอยู่จริง ตรงประเภท ไม่ผูกซ้ำ แล้วเก็บเป็นฉบับใหม่
(แก้ไม่ได้) · "แสดงในหน้าจอง" เลือกได้ทีละแผนผัง · ประวัติฉบับ: "เผยแพร่ฉบับนี้อีกครั้ง" (ย้อนฉบับ) หรือ "คัดลอกไปเป็นร่าง" ·
ชั้นที่ซ่อนอยู่ไม่ถูกส่งไปหน้าจอง

**จุดอ้างอิงพิกัด (แผนผังรูปถ่าย)**: แท็บพื้นหลัง → "เพิ่มจุดอ้างอิง" → คลิกบนรูปตรงจุดที่รู้พิกัด → วางพิกัดจาก Google Maps
(คลิกขวาที่จุด → คลิกตัวเลขพิกัด) · อย่างน้อย 2 จุด (3 จุดขึ้นไปที่ห่างกันแม่นกว่า) · ระบบบอกความคลาดเคลื่อนของแต่ละจุด ·
จากนั้นวัดระยะจริงได้ และกด **"สร้างแผนผังดาวเทียมจากรูปนี้"** ได้ (สร้างแผนผังใหม่ แผนผังเดิมไม่เปลี่ยน)

**แผนผังดาวเทียม**: แท็บพื้นหลัง → จุดกึ่งกลาง (วางพิกัด หรือ "ใช้กึ่งกลางของจอตอนนี้") และระดับซูม 13–19 · ย้ายกรอบแล้ว
ชิ้นต่าง ๆ อยู่ที่เดิมบนพื้นโลก · ภาพดาวเทียมมีเฉพาะรอบกรอบแผนผัง (กรอบ + อีก 1 กรอบโดยรอบ) — วาดไว้ไกลกว่านั้นจะไม่มีภาพใต้ชิ้นนั้น

## 4. หน้าจอง

- ก่อนค้นหาวันที่: แผนผังไม่มีสี · หลังค้นหา: ขอบเขียว = ว่าง, สีเข้ม = ไม่ว่าง, ขอบส้ม ✓ = เลือกแล้ว
- แตะบ้าน / เต็นท์ → กล่องรายละเอียดเหมือนการ์ดในรายการ (รูป ชื่อ ความจุ ราคาตามช่วงวันที่) + ปุ่มเลือก
- ลานกางเต็นท์: จำนวนเต็นท์ที่เหลือ + ปุ่มไปฟอร์มจองลานกางเต็นท์
- ใช้คีย์บอร์ดได้ (Tab + Enter) · ลิงก์ "ข้ามแผนผัง ไปที่รายการที่พัก" · รายการที่พักด้านล่างยังอยู่ครบเป็นทางเลือก
- **สีบนแผนผังเป็นเพียงภาพประกอบ** — ราคาและห้องว่างมาจากระบบจองเดิม และ server ตรวจซ้ำทุกครั้งที่ขอราคาและยืนยันการจอง
  (กันจองซ้ำ / เกินจำนวนด้วย transaction เดิม) แผนผังไม่เคยแก้การจอง ราคา หรือ snapshot ราคาที่มีอยู่
- แผนผังดาวเทียมแสดงเครดิต © MapTiler © OpenStreetMap contributors เสมอ (เงื่อนไขของผู้ให้บริการ)
